Simple setup guide

Start using Marketplace Bot

Choose the Facebook account first, then open the task you want. The five everyday tools stay in the sidebar; setup and less-used options are inside More Tools.

1
Add an accountOpen More Tools → Accounts and sign in to Facebook.
2
Select itChoose the correct account from the top bar.
3
Start a taskPick a tool from the sidebar and follow its buttons.

Main tasks

01

Create Listings

Publish one listing manually or several listings from an Excel file.

  • Add the required listing details.
  • Use at least one valid image.
  • Leave enough delay between multiple posts.
02

Manage Listings

  1. Click Import Listings and wait until it finishes.
  2. Select listings when you want to delete several.
  3. Clear All Listings only removes saved app data, not Facebook listings.
03

Repost a Listing

  1. Import listings in Manage Listings.
  2. Click Repost beside one listing.
  3. Choose the delay and schedule it.
  4. Check progress on the Reposting page.
04

Auto Reply

Set the reply message and start Auto Reply for the selected account.

  • Use More Tools → Reply Status to check it.
  • Keep the Facebook account signed in.
05

Groups

Open More Tools → Groups to add or import groups. Use Group Posting to publish to the selected groups.

06

Schedules and Activity

Open More Tools to view Scheduled Posts, Reply Status, and the Activity Log whenever you need to check progress.

!

Before running automation

  • Confirm the correct active account at the top.
  • Keep the app running while work is scheduled or in progress.
  • If Facebook requests verification, sign in again before retrying.
  • Do not schedule posting actions too close together.
